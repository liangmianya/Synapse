# Synapse Design System

> **版本**: v1.0 | **日期**: 2026-08-07 | **适用产品**: Synapse — 非线性学习伴侣

---

## 1. 设计哲学

> **学习的形态不是线，而是网。设计应该匹配认知的自然结构，而不是强迫认知适应工具的限制。**

### 1.1 空间优先（Spatial First）

人类空间记忆远强于序列记忆。Synapse 将对话放在空间画布上，利用空间记忆帮助用户在知识网络中导航。位置有意义，距离有含义，方向有含义。

### 1.2 认知减负（Cognitive Calm）

学习已经够累，界面不应增加认知负担。克制的色彩、清晰的层级、可预测的交互——让界面退到背景中，让内容成为主角。

### 1.3 有机生长（Organic Growth）

知识不是规划出来的，是探索出来的。界面像知识本身一样有机生长——新分支自然延伸，关联自然形成。渐进式揭示，非破坏性扩展。

---

## 2. 设计原则

| 原则 | 规则 | 反模式 |
|------|------|--------|
| 层次即信息 | 视觉权重反映重要性，一个画面一个焦点 | 多元素同等强调 |
| 空间即记忆 | 画布位置是信息的一部分，相关线索靠近 | 自动重排破坏空间记忆 |
| 克制即自信 | 每个视觉元素要有存在的理由 | 装饰性渐变、无意义动效 |
| 一致即信任 | 相同操作产生相同视觉反馈 | 相同功能用不同样式 |
| 过渡即引导 | 动效帮用户理解状态变化 | 瞬间跳变让用户迷失 |
| 密度即效率 | 信息密度匹配场景（画布低/对话高） | 全局统一密度 |

### 3.1 色彩哲学

暖中性底色 + 单一强调色。Stone 暖灰构建沉稳基底，Teal 传达智能与深度，Amber 仅在顿悟时刻点缀。

## 7. 阴影与层级

### 层级模型

| 层级 | 名称 | 阴影 | 用途 |
|------|------|------|------|
| 0 | 基底 | 无 | 画布背景 |
| 1 | 表面 | `--shadow-sm` | 卡片、输入框 |
| 2 | 浮起 | `--shadow-md` | 悬浮卡片、下拉 |
| 3 | 弹出 | `--shadow-lg` | 弹窗、提示 |
| 4 | 模态 | `--shadow-xl` | 全屏模态 |

### 阴影定义（Stone 色调染色）

```css
--shadow-sm: 0 1px 2px rgba(28,25,23,0.05);
--shadow-md: 0 4px 8px rgba(28,25,23,0.06), 0 1px 2px rgba(28,25,23,0.04);
--shadow-lg: 0 12px 24px rgba(28,25,23,0.08), 0 4px 8px rgba(28,25,23,0.04);
--shadow-xl: 0 24px 48px rgba(28,25,23,0.10), 0 8px 16px rgba(28,25,23,0.06);
--shadow-focus: 0 0 0 3px rgba(13,148,136,0.15);
```

### 边框策略

阴影与边框不叠加，选择其一：卡片默认用 1px 边框；悬浮时加 `--shadow-md`；弹出层用无边框+阴影。

## 11. 动效系统

### 原则

1. 动效服务于理解
2. 快进慢出（进入 150ms，退出 250ms）
3. 空间连续性（有轨迹不瞬移）
4. 不过度（>400ms 需充分理由）

### 规格

| Token | 时长 | 缓动 | 用途 |
|-------|------|------|------|
| `--duration-instant` | 100ms | ease-out | 按下、选中 |
| `--duration-fast` | 150ms | ease-out | 悬浮、颜色变化 |
| `--duration-normal` | 250ms | cubic-bezier(0.4,0,0.2,1) | 面板展开、模态 |
| `--duration-slow` | 400ms | cubic-bezier(0.4,0,0.2,1) | 缩放、视图切换 |
| `--duration-deliberate` | 600ms | cubic-bezier(0.34,1.56,0.64,1) | 分支创建、关联绘制 |

### 具体动效

| 场景 | 动效 |
|------|------|
| 卡片出现 | opacity 0→1 + translateY(8→0)，250ms |
| 分支创建 | 连接线绘制(400ms) → 子卡片淡入(250ms,延迟200ms) |
| 线索展开 | 尺寸过渡 + 内容淡入，250ms |
| 对比视图 | 画布淡出 + 各列滑入，400ms |
| 消息发送 | 气泡从输入区展开，150ms |

## 14. 内容规范

### 语气

| 场景 | 语气 | 示例 |
|------|------|------|
| 空状态 | 鼓励不夸张 | "双击画布任意位置，开始第一条线索" |
| 错误 | 直接可操作 | "网络断开，正在重试…" |
| 成功 | 简洁 | "已保存" |
| 引导 | 轻量 | "试试 Cmd+K 快速搜索" |

### 规则

- 不用感叹号（警告除外）
- 不用「请」——这是工具不是客服
- 按钮用动词：「创建分支」非「分支」
- 数字用阿拉伯数字
